<objective>
Replace the image re-injection path used during a Scribe **Replace** — currently a text marker (` IMG:N `) plus a per-image, post-`callCommand` async `PasteHtml` — with a **plugin-only** path that (1) captures each referenced image's full drawing `ToJSON`, (2) registers its media via the stock `getLocalImagePath` plugin method in an async pre-pass, then (3) rewrites the blip and inserts text AND images together via `Api.FromJSON` + `AddDrawing` inside the **single** injection `callCommand`. This fixes the four live-reproduced bugs at once — multiple undos, flicker, lost selection, lost image fidelity — for images in **table cells** AND in **paragraphs** (shared path). Zero sdkjs modification.

Purpose: One `callCommand` = one history point = one undo, one repaint, and the end-of-callCommand post-selection (fix L#2) stays authoritative. `FromJSON` restores every attribute the `<img>`-based PasteHtml dropped (crop, rotation, flip, wrap/anchor, effects, alt-text, ratio-lock).
Output: Refactored `plugins/onlyoffice-scribe/scripts/code.js` (only production file this phase touches).
</objective>
